# PetroDesk — آزمون جمع‌آوری برچسب‌های خبر فارسی و گزارش اخبار جامانده

**وضعیت تحویل:** کد و تست‌های محلی آماده است؛ اتصال زنده GitHub هنوز در حساب شما آزموده نشده و خودکارسازی تا قبل از تأیید واقعی فعال نشده است.

## هدف

- سه صفحه «پتروشیمی»، «صنعت پتروشیمی» و «شرکت پتروشیمی» را از محیط مستقل GitHub Actions **با رعایت robots.txt و بدون عبور از محدودیت سایت** تست کند.
- در صورت دریافت صفحه و استخراج معتبر لینک‌های `/u/شناسه`، لینک خبرها را در `docs/items.json` و یک RSS آزمایشی `docs/feed.xml` ذخیره کند.
- فقط عنوان، لینک و زمان کشف ثبت می‌شود؛ **زمان کشف زمان انتشار خبر نیست.** RSS جایگزین متن کامل ناشر نیست.
- از طریق Google Apps Script، خبرهای احتمالی جامانده را با بانک Google Sheets مقایسه کند؛ همسانی دقیق را جدا کند و شباهت احتمالی را به‌عنوان نیازمند بررسی نگه دارد.
- هوش مصنوعی فقط در چت عادی ChatGPT کار می‌کند؛ API پولی و انتشار خودکار در تلگرام وجود ندارد.

## مرحله ۱ — آزمایش مستقل GitHub

1. از GitHub یک مخزن جدید بسازید. برای اینکه فایل JSON به Google Sheets برسد، در این نسخه مخزن باید **Public** باشد. فقط عنوان و لینک خبرهای عمومی در آن قرار می‌گیرد؛ بانک خصوصی گوگل به GitHub منتقل نمی‌شود.
2. محتویات همین پوشه را عیناً به ریشه مخزن منتقل کنید، به‌طوری که `.github/workflows/collect.yml` در همین مسیر باشد. اگر مرورگر فایل‌های مخفی را نشان نمی‌دهد، از روش آپلود فایل جداگانه استفاده کنید. **فقط ZIP را آپلود نکنید؛ محتویات ZIP باید استخراج شده باشند.**
3. در GitHub به تب **Actions** بروید؛ Workflow با عنوان «PetroDesk public tag discovery» را باز کنید و روی **Run workflow** بزنید.
4. بعد از پایان اجرا، در log خطوط `HTTP ...` یا `robots...` و شمار `Item count` را بررسی کنید. سپس فایل `docs/coverage_status.json` را باز کنید. فقط اگر حداقل یک منبع `status: ok` و `count > 0` داشت، اتصال زنده تأیید شده است.
5. اگر همه منابع `HTTP 403`، `robots unavailable`، `parser-empty` یا `network-error` داشتند، آن اتصال را **موفق اعلام نکنید**. فید قدیمی در صورت وجود حفظ می‌شود، اما انتشار جدیدی کشف نشده است. برای پوشش جامع باید سراغ مسیر رسمی از صاحب سایت برویم.
6. Workflow هر نیم ساعت درخواست می‌دهد؛ GitHub می‌تواند اجرای زمان‌بندی‌شده را دیرتر انجام دهد یا گاهی نوبتی را از دست بدهد. برای شروع هر چند ساعت گزارش وضعیت را نگاه کنید. برای مخزن عمومی، اجرای استاندارد GitHub Actions معمولاً رایگان است؛ مخزن خصوصی سهمیه ماهانه دارد.

### نشانی JSON پس از ایجاد مخزن

`https://raw.githubusercontent.com/OWNER/REPO/main/docs/items.json`

مقدار `OWNER` و `REPO` را با مشخصات واقعی مخزن جایگزین کنید. اگر شاخه پیش‌فرض غیر از `main` بود، نام آن را جایگزین کنید. پیش از اتصال Google Sheets، همین لینک را در مرورگر باز کنید و وجود `"schema": 1` و `"items"` را ببینید.

## مرحله ۲ — اتصال به بانک فعلی Google Sheets

1. در Apps Script پروژه `PetroDesk Collector` با علامت `+` یک **Script file** به نام `CoverageBridgeV8` اضافه کنید.
2. محتوای `PetroDesk_CoverageBridge.gs` را در آن قرار دهید. **کد `Code.gs` و سایر افزونه‌ها را پاک نکنید.**
3. داخل تنظیمات ابتدای فایل مقدار `PDCOVER8.publicJsonUrl` را به لینک عمومی واقعی `items.json` تغییر دهید.
4. `pdCover8SelfTest` را اجرا کنید؛ باید «All 4 ... passed» ببینید.
5. `pdCover8Probe` را اجرا کنید؛ این مرحله **فقط خواندنی** است. تعداد خبرهای اخیر و نامزدهای جامانده گزارش می‌شود.
6. سپس `pdCover8DailyReport` را دستی اجرا کنید؛ گزارش در برگه **گزارش اختلاف خودکار** و خلاصه منبع در **وضعیت پوشش منابع** ثبت می‌شود.
7. بعد از بررسی دستی چند خبر، تابع `pdCover8Import` را اجرا کنید تا فقط خبرهای *قطعاً غیرتکراری از نظر عنوان/لینک* در «ورودی اخبار» به‌صورت **نامزد** ثبت شوند. متن کامل و تاریخ اصلی خالی می‌مانند و نیازمند بررسی‌اند.
8. فقط وقتی همه موارد فوق تأیید شدند، `pdCover8Setup` را برای زمان‌بندی روزانه گزارش و نیم‌ساعتی جمع‌آوری اجرا کنید.
9. برای توقف **فقط** وظایف جدید، تابع `pdCover8Pause` را اجرا کنید. این تابع به جمع‌آورنده قبلی دست نمی‌زند.

## محدودیت‌ها و قواعد مهم

- امکان دریافت خودکار صفحه از سرور GitHub از قبل **تأیید نشده**؛ این یک آزمون اجراپذیر است و باید در حساب شما اجرا شود.
- الگوریتم `parse_cards` صرفاً لینک‌های `/u/شناسه` را استخراج می‌کند؛ اگر HTML سایت تغییر کند، ممکن است `parser-empty` شود. خطای این مرحله نباید به‌عنوان «هیچ خبری نبود» ثبت شود.
- گزارش «جامانده» برابر با «قطعاً از دست رفته» نیست. تطبیق معنا و رویداد توسط ChatGPT و تأیید سردبیر انجام می‌شود.
- اخباری که تاریخ نشر واقعی ندارند نباید در بسته «۲۴ ساعت گذشته» به‌عنوان خبر تازه معرفی شوند. زمان کشف فقط مشخص می‌کند از چه زمانی سیستم آن را مشاهده کرده است.
- جمع‌آوری ۲۰ کانال تلگرام و سایت صاحب‌خبر **با این بسته پوشش داده نمی‌شوند** و به دسترسی مستقل و مجاز نیاز دارند.
- بازنشر متن کامل از خبر فارسی انجام نمی‌شود؛ فقط لینک و عنوان برای کشف ذخیره می‌شوند و متن اصلی از رسانه ناشر بررسی می‌شود.
- اگر سایت اجازه دریافت خودکار نداد، از دورزدن محدودیت خودداری کنید و درخواست فید رسمی یا سرویس اتاق خبر بدهید.
